## 🛠️ What I'm building

### 🗓️ Bicho — Booking SaaS for small businesses · [website](https://bichomx.com) · [live demo](https://reservas-saas-sigma.vercel.app/t/dental-nova)
A **multi-tenant** platform: every business (dentists, salons, gyms, restaurants) gets its own booking page, calendar, PDF quotes and WhatsApp confirmations.
- **Atomic bookings** in PostgreSQL — double booking is impossible by design
- **Tenant isolation** with Row Level Security
- **Semantic search** over services with embeddings (pgvector)
- 🔜 **AI agent** that answers WhatsApp and books appointments on its own

`Next.js` `React` `TypeScript` `Supabase` `PostgreSQL` `pgvector` `Stripe` `WhatsApp Cloud API` `Vercel`
